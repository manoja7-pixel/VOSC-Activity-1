# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built with plain HTML, CSS and JavaScript.

# Functionality

- The interface takes the players names as inputs and assigns them X or O symbol. A start button is present which powers up the interactive 3x3 tic-taac-toe square. Player with X symbol starts the game. 
- In the javascript the conditions for winning are defined a 2D array which basically contains the row, column and diagonal values which indicate the positions of the symbols in the 3X3 sqaure.
- After all the 9 boxes are filled, the winner is declared and the interface asks the user if they want a rematch or start a new game as a whole.
